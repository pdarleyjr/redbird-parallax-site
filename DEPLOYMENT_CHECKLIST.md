# Release checklist

- [ ] Review the PR and its exact source commit.
- [ ] Confirm the approved map, 31 houses and 6–9 PM hours remain current.
- [ ] Keep registration hidden unless a reviewed 2026 form is supplied.
- [ ] Review npm run check, npm test and npm run test:browser, including docs/QA-REPORT-2026.md.
- [ ] Actual iPhone: menu/rotation, full PNG/pinch zoom/save to Photos or Files, PDF save/print.
- [ ] Actual Android: menu/rotation, PNG opening/saving, PDF opening/printing.
- [ ] Obtain explicit production merge/release authorization.
- [ ] After release, verify Pages status, deployed title/date/count and map hashes. Measure deployed mobile Lighthouse.
- [ ] Repeat changed visitor workflows at the production repository prefix.

Pages publishes from main. No deployment, Pages-settings change, domain change or DNS change is authorized by this checklist.
