## 4. UX/UI specification (Deliverable 4)

### 4.1 Brand system — "Red Bird Neighborhood" (owner directive, 2026-10-16)

**Source of truth:** the owner's 2026 "Red Bird Trick-or-Treat Trail — Year Two" flyer, saved at [`brand/redbird-flyer-2026.webp`](brand/redbird-flyer-2026.webp). Its palette is **the Red Bird Neighborhood brand palette** and applies across the whole app: the shared homepage, the Halloween experience, the admin, the PWA icon/splash, the map night style and (later) Christmas. It **replaces** the earlier `#0b0e1d` / `#ff7a1a` scheme. Every color below was sampled from the flyer's pixels (dominant-color and neon-core analysis), not guessed.

**Flyer anatomy (what to carry into the UI):**
1. **Night sky:** saturated midnight navy at the top (`#022255`), deepening to near-black navy behind the silhouettes (`#000a20`). A thin twilight band near the horizon goes violet-plum (`#34173c`), then ember-red (`#a62d2e`) right at the rooftops.
2. **Neon marquee sign:** a dark ink-plum panel (`#131127`) outlined by a glowing cardinal-red neon tube. The tube has a bright core (`#e8200c`) inside a deeper red bloom (`#b50201`). "RED BIRD" is set in outlined neon caps; "TRICK-OR-TREAT TRAIL" is in warm cream (`#fbf3e3`), wide-tracked geometric caps.
3. **Cardinal:** the hero mark sits on top of the sign, rendered in neon reds (`#ed0301` / `#ea2308`).
4. **Arrow banner:** cream marquee board (`#fdeed3`) with dark ink text (`#08132b`) and a neon orange-red outline (`#f85818`). This is the model for **primary buttons**.
5. **Accents:** violet neon rules (`#8858c8`, pale core `#f4dafe`), 4-point gold sparkle stars (`#fcd272`), a full moon in warm cream (`#fddaa4`), amber lit windows (`#fa8e29`), and the coral neon script tagline (`#f9a066`).
6. **Silhouettes:** palms and houses in near-black navy (`#000a20`) along the bottom edge. The mood is a warm, glowing Miami neighborhood at night: festive but not gory.

- **Signature background:** `linear-gradient(180deg, var(--rb-sky) 0%, #01204f 55%, var(--rb-sky-deep) 82%, var(--rb-twilight) 92%, var(--rb-ember) 100%)`. Use it only on the page/hero canvas, where it reproduces the flyer's sky. **No other decorative gradients.** Optional fixed bottom silhouette strip (inline SVG palms + houses with `--rb-amber` windows, ≤6 KB) on the homepage and Halloween hero only.
- **Neon treatment** (`.neon` utilities, CSS only, no images). Outline: `box-shadow: 0 0 0 2px var(--rb-cardinal), 0 0 12px 2px rgb(232 32 12 / .55), inset 0 0 10px rgb(232 32 12 / .35)`. Text: `text-shadow: 0 0 6px rgb(232 32 12 / .7), 0 0 18px rgb(181 2 1 / .6)` over `color: var(--rb-cardinal)` or cream. Use it for the wordmark, the event-card frames, the active-nav underline and the map's selected marker. **Do not** use it on body text, on more than ~3 elements per viewport, or as `filter: blur` on large areas (performance). With `prefers-reduced-motion: no-preference`, play a single 600 ms "power-on" flicker on first paint of the wordmark only; never loop it.
- **Buttons:**
  - **Primary:** "marquee" style. `--rb-cream` fill, `--rb-ink` text (≈15:1), 2 px `--rb-neon-orange` border with a soft orange glow; hover brightens the glow; pressed uses `--rb-cardinal-deep` border.
  - **Secondary:** transparent, cream text, 1.5 px cream/40% border.
  - **Never** cream or white text on a red fill: `#fdeed3` on `#e8200c` is only ≈3.9:1, which fails AA for normal text.
- **Contrast rules (computed):**

  | Pair | Ratio | Allowed use |
  |---|---|---|
  | `--rb-text` on `--rb-sky` | ≈13:1 | Body text |
  | `--rb-neon-orange` on `--rb-sky` | ≈4.8:1 | Links, labels |
  | `--rb-coral` on `--rb-sky` | ≈7.5:1 | Any text |
  | `--rb-cardinal` on `--rb-sky` | ≈3.4:1 | **Large text ≥24 px/bold 19 px, borders and icons only.** Never body copy |

- **Typography:**
  - **Display:** Poppins 700 (existing self-hosted woff2). Its geometric caps match the flyer's sign lettering. Use uppercase with `letter-spacing: .12em` for eyebrows and "TRICK-OR-TREAT TRAIL"-style subtitles.
  - **Body:** `system-ui`.
  - **Script accent (optional):** one self-hosted, Latin-subset OFL script face (e.g. *Yellowtail*, ≤25 KB woff2, `font-display: swap`), used **only** for the tagline line "Same Neighborhood. More Halloween Magic." / seasonal taglines, in `--rb-coral` with a light neon text-shadow.
  - **Scale:** `--step-0 clamp(1rem,.95rem+.25vw,1.125rem)` … `--step-5 clamp(2.25rem,1.6rem+3.2vw,4rem)`.
- **Shape and space:** card radius 1.25 rem; the neon frame follows the radius. Spacing uses the existing `--space`. No glassmorphism.
- **Motifs (reuse sparingly):** 4-point gold sparkle star (inline SVG symbol), full moon disk (`--rb-moon`, on the homepage hero only), violet double-rule divider (two 2 px `--rb-violet` lines with `--rb-violet-core` 1 px centers), marquee arrow banner for date callouts (cream board, ink text, orange neon edge, right-pointing arrow tip via `clip-path`).
- **Wordmark:** "RED BIRD" in neon cardinal outlined caps (Poppins 700, `-webkit-text-stroke` + neon text-shadow, solid cream fallback when `@supports not (-webkit-text-stroke: 1px)`), over "NEIGHBORHOOD HOLIDAY TRAILS" in cream tracked caps. The Halloween page's lockup uses "TRICK-OR-TREAT TRAIL" as the second line, like the flyer. The cardinal mark is a new simplified inline SVG cardinal in `--rb-cardinal` / `--rb-cardinal-deep` with a cream eye highlight, traced in spirit from the flyer, not copied. Keep `assets/img/trail/cardinal.webp` as the raster fallback.
- **Seasonal themes:**
  - The brand palette above is shared by every season.
  - `[data-theme="halloween"]` keeps it as-is, with `--accent: var(--rb-neon-orange)`.
  - `[data-theme="christmas"]` (ready, inactive until activation): same navy, cardinal and cream base, with `--accent: var(--rb-gold)` and an optional `--rb-evergreen #0a3d2e` used only for small decorative details. It must not introduce a competing background color.
- **Applies to:**
  - Homepage and Halloween pages.
  - Admin UI.
  - The 404 and offline pages.
  - Install/update sheets.
  - The PWA app icon: neon cardinal on `--rb-sky` with a thin cream marquee ring; maskable variant padded.
  - The splash colors.
  - The map night style (§5.7 in 05-TECH-SPEC).
  - Print is deliberately **light** (white paper, `--rb-ink` text, `--rb-cardinal` numbered markers, `--rb-neon-orange` boundary) to save ink while keeping brand color in the markers and title.

### 4.2 Shared homepage `/`
- **Mobile (≤699 px):** header (cardinal + wordmark, no menu). Hero line: "Two neighborhood trails, one Red Bird." (≤1 line of supporting text). Two stacked cards, full container width, aspect 4:5 (≈ 340–400 px tall), 16 px gap:
  - **Halloween card** = one `<a href="halloween/">` (entire card is the target). Art: existing hero webp (600/960/1536) with a `--rb-sky-deep` bottom scrim; **neon cardinal frame** (`.neon` outline); eyebrow "HALLOWEEN" in tracked `--rb-neon-orange` caps; title "Red Bird Trick-or-Treat Trail"; meta "Saturday, October 31, 2026 · 6–9 PM"; live count "46 houses on the map" (from snapshot; omitted if unknown); marquee-style primary CTA "Explore the trail →" (cream board, ink text, orange neon edge). States: hover lift 2 px + glow brightens, focus 3 px `--rb-neon-orange` ring with 3 px offset, active scale .99.
  - **Christmas card** = `<article class="event-card is-updating" aria-labelledby=… aria-describedby=…>` (**not** a link, no button, no tabindex). Art: `red_bird_holiday_trail` webp, desaturated (`filter: saturate(.35) brightness(.7)`); plain 1 px `--rb-line` frame (**neon off** — an unlit sign signals "not open yet"); `--rb-gold` ribbon badge with `--rb-ink` text text **"Updating for this year's event"**; title "Red Bird Neighborhood Holiday Trail"; body "Details for this year’s holiday trail will be posted here." Cursor default; no hover effect. Screen readers read title + "Updating for this year's event" (visually-hidden "Not yet available").
- **Desktop (≥960 px):** two-column grid, max 1200 px, cards aspect 5:6, Halloween left. Above the cards, the wordmark sits in a marquee-panel lockup (neon "RED BIRD", cream "NEIGHBORHOOD HOLIDAY TRAILS", violet double-rule, gold sparkles, moon top-left); palm/house silhouette strip along the bottom of the hero.
- Below cards: "Add Red Bird Trails to your home screen" install affordance (§4.7), brief footer (neighborhood, © 2026, attribution link to /about-data anchor).
- **Activation rule:** card rendering comes from events registry status: `published` → link to `christmas/` (or `halloween/`) with full styling; `updating` → inactive card above; `archived` → card stays visible, links to the event page, badge "This year’s trail has ended"; `draft` → card hidden.

### 4.3 Halloween experience `/halloween/`
- Keeps existing sections and copy (hero, what to expect, how it works, houses, community) and theme; adds a **header "← Holiday Trails" link** to `../` (also first item in mobile menu).
- **Mobile action bar** (fixed bottom, safe-area padded, 64 px + inset): `Map` · `Near me` · `Houses` · `Print`. `Near me` scrolls to the map and starts location. Hidden on desktop (desktop nav has same items).
- **Map section `#map`:** on mobile the map is `height: calc(100svh - header - actionbar)`; desktop 640 px tall in a 2-column layout with a scrollable house list beside it (list ↔ map selection sync).
  - Before load: lightweight poster (pre-rendered basemap webp, ~60 KB) + spinner; MapLibre loads when `#map` is within 600 px of viewport, or immediately on any map control tap.
  - Floating controls (right, 48 px round, labeled): **Find my location** (primary marquee style: cream fill, ink icon, orange neon edge), zoom +/−, "Show whole trail".
  - **Nearest house card** (bottom sheet, appears once location is active): big directional arrow, "Nearest: #12 Phantasmal Phountain", "About 240 ft · Northeast (straight-line)", buttons: `Show on map`, `Mark visited`, `Next nearest`, `Walking directions ↗`. Compass toggle "Point arrow using compass" (shows only where supported).
  - **Markers (overlap-aware):** houses are a GeoJSON source rendered by MapLibre layers, not 46 DOM elements — several stops are only 20–30 m apart (5785/5790/5792/5795 SW 39th St; 3601/3610 SW 60th Ave plus a new neighbor) and z16 ≈ 2.15 m/px. Layers: (1) `house-dot` circle (r 9 px z15 → 13 px z18, `--rb-cardinal` fill, `--rb-cream` 2 px stroke, cream numerals; always drawn, `circle-sort-key = mapNumber`); (2) `house-number` symbol (number text in the dot, `text-allow-overlap: true` on the dot itself); (3) `house-icon` symbol (illustrated icon via `addImage`, 44 px, only at z ≥ 17.5, `icon-allow-overlap: false`, `symbol-sort-key = mapNumber`, collisions hide the icon but never the numbered dot). State via `feature-state`: selected (neon cardinal glow ring + raised), nearest (`--rb-gold` double ring; pulse only without reduced motion), visited (`--rb-panel-raised` dot + `--rb-amber` ✓), approximate (dashed outer ring via second circle layer with lower opacity). Tap: `queryRenderedFeatures` with a 22 px hit box; if >1 feature hit, show a small chooser sheet listing those houses. The selected house additionally gets one DOM `<button>` marker for focus/announce. **Accessible equivalent:** the "Houses on the map" list (beside the map on desktop, a sheet on mobile) — every item is a button that selects/flies to the house; keyboard users operate the map through this list. Tap → house sheet (icon, number, name, address, description, Visited toggle, Directions).
  - User location: blue dot (#2b7fff, white 3 px border) + translucent accuracy circle; follow mode until the user pans.
  - Status messages via one `aria-live="polite"` region (permission denied, low accuracy, outside area, map offline).
- **Houses section:** existing searchable grid; each card gains "Show on map" and a Visited checkbox; header shows "7 of 46 visited · Reset".
- **Archival map:** removed from primary actions; a collapsed "Original October 9 map (31 houses — superseded)" disclosure keeps the PNG/PDF links with a visible "Out of date" label.

### 4.4 Interaction/permission copy (exact)
- Before prompt (first tap): "We use your location only on this device to show where you are. It’s never sent anywhere."
- Denied: "Location is off for this site. You can still browse the map and the house list. To turn it on, allow location for this site in your browser settings."
- Low accuracy (>75 m): "Your location is approximate (±{n} ft)."
- Outside area (>400 m from boundary): "You appear to be outside the Red Bird trail area."
- All visited: "You’ve visited every house on your list! 🎃" + `Reset visited`.

### 4.5 Print `/halloween/print/`
- Screen view: preview of the page + controls: Paper `Letter portrait` (default) / `Letter landscape`; "Include house list" (default on); `Print or save as PDF` button (disabled until "Map ready ✓"). Platform hint: iOS "Share → Print → Save to Files", Android "⋮ → Share → Print → Save as PDF".
- Printed page (Letter portrait): header band (white bg): "Red Bird Trick-or-Treat Trail" + "Saturday, October 31, 2026 · 6–9 PM". Map block 7.5×6.2 in: light basemap, readable street labels (≥7 pt equiv), numbered `--rb-cardinal` circles (0.22 in, white numerals 7 pt) with optional tiny icons, north arrow, scale bar (ft). Legend below in 3 columns (number, name, address; 7.5 pt), wraps to page 2 automatically if >60 houses. Footer: "Data version {v} · updated {date}", "Map data © OpenStreetMap contributors · Protomaps", site URL. No nav, no GPS dot, no admin UI. `@page { size: letter; margin: .4in }`, `print-color-adjust: exact`.

### 4.6 Admin (`redbird-admin` host)
- Same tokens, light-on-dark compact layout, desktop-first but usable on a phone.
- **Manage Houses:** stat chips (Published 46 · Drafts 0 · Needs review 6 · Approximate pins 46); search; table/list: #, icon, name, address, location status, publication status, `Edit`. Filter chips: All / Needs review / Drafts / Archived.
- **House editor (Add/Edit):** steps in one page — Details (name, address, optional description ≤280 chars) → Location (map with draggable pin; `Suggest from address` → geocode; "Pin is on the correct house front" checkbox ⇒ `verified`) → Icon (grid: custom icons first, then generic; preview at both marker sizes) → Preview (public card + marker) → `Save draft` / `Publish` / `Unpublish` / `Archive`. Saving a published house shows "This updates the public map immediately."
- **Import:** drop CSV → client parse → header-mapping confirmation (shows which columns will be *ignored* as private) → preview table grouped: New · Name changes · Duplicates/conflicts · Incomplete · Unchanged; per-row Accept/Reject; `Apply accepted (n)`; batch history with `Undo batch`.
- **Versions:** list of published snapshots (version, time, actor, house count, diff summary) with `Restore`.
- **Events:** Halloween 2026 / Christmas 2026 status selector (draft · updating · published · archived) with confirmation dialog; Christmas details form (title, date, hours, description, art choice) required before `published` is allowed.
- **Activity:** last 100 audit entries.

### 4.7 PWA install UI
- Android/Chromium: capture `beforeinstallprompt`; show `Install app` button (footer + Halloween menu); call `prompt()` on tap; hide when installed (`appinstalled`, `display-mode: standalone`).
- iOS Safari (not standalone): `Add to Home Screen` button opens a small sheet: "1. Tap Share ⬆︎ 2. Tap Add to Home Screen 3. Keep ‘Open as Web App’ on." Never auto-pop; dismissal stored 14 days.
- Update toast (bottom, above action bar): "A new version of Red Bird Trails is ready. [Refresh]" — never auto-reload; deferred while location tracking is active until the user stops it or taps Refresh.

### 4.8 Accessibility (WCAG 2.2 AA)
Skip link; landmarks; visible focus; all controls ≥44 px (primary ≥48); contrast ≥4.5:1 text per the computed pairs in §4.1 (cardinal red is large-text/UI-only at ≈3.4:1; card text over art uses a `--rb-sky-deep` scrim to keep ≥4.5:1); map markers are focusable buttons with full labels; keyboard: arrow keys pan, +/- zoom (MapLibre built-in), Tab through markers in number order; status via `aria-live`; inactive Christmas card is non-interactive text with explicit "not yet available"; reduced motion disables twinkle, pulse, fly-to animation (jump instead).
