## 6. Acceptance criteria & QA (Deliverable 6)

### 6.1 Automated (CI must be green)
- **Unit (`node --test tests/unit`)**: address normalization table (every Oct 16 variant); names; CSV parser (RFC 4180, BOM, CRLF, quoted newlines, trailing-space headers, header aliasing); reconciliation against `tests/fixtures/registrations-2026-10-16.sanitized.csv` (date/address/house-name only + synthetic `redacted@example.invalid` contact columns; committed only after G2, else test skips with message) asserting: 47 rows, 46 keys, 31 matched with ids preserved, 15 new = the §2.2 list, `duplicate_conflict` at 3800 SW 58th Ave, `incomplete_name` at 5792 SW 39th St, `zip_mismatch` on [new #38 address], re-import ⇒ 0 new (idempotent), no published house removed; numbering rules; geo math; snapshot schema (rejects extra fields, e.g. `email`); **privacy scan**: every tracked file (`git ls-files`) contains no email/phone patterns except allowlisted test placeholders, and `private/` is ignored; build `--check`; no root-absolute URLs in generated output; content rules ported from current `content.test.mjs` (date labels, no 2024/2025 strings in Halloween pages, `textContent`-only — `innerHTML` banned except none).
- **Worker (`vitest` + Workers pool, D1 migrations applied)**: unauthenticated / wrong-aud / non-allowlisted → 401/403 on every admin route; valid JWT fixtures (locally signed JWKS) → success; duplicate address create → 409; out-of-boundary coords → 422; publish/unpublish regenerate snapshot with incremented version and correct house set; If-Match conflict → 409; import preview classification == unit expectations; apply then rollback restores prior rows and snapshot; repeated preview of same file flags known fingerprints; public routes reject POST; public payload never contains non-schema fields; events status transitions validated.
- **E2E (`@playwright/test`)** projects: `chromium-mobile` (Pixel 7), `webkit-mobile` (iPhone 15), `chromium-desktop` 1440×1000, `webkit-desktop`, `firefox-desktop`; plus the existing 9 Chromium viewports for overflow/axe sweeps. Specs:
  - home: two cards; Halloween is a link to `halloween/`; Christmas has no `a`/`button`/tabindex, text "Updating for this year's event", click does not navigate; legacy `/#map` redirects to `halloween/#map`; axe 0 violations; no horizontal overflow at 320 px.
  - halloween: date "Saturday, October 31, 2026", "6 PM–9 PM"; directory count == snapshot published count (read from the snapshot, never a literal); all 31 original ids `stop-01..31` present; back link to home; mobile action bar targets ≥44 px; existing menu tests ported.
  - map (Chromium launched with `--use-angle=swiftshader --enable-unsafe-swiftshader`; WebKit-Linux map specs best-effort): lazy (MapLibre not requested on home or before scroll); every located snapshot house has exactly one rendered feature (`queryRenderedFeatures`) with correct number; houses with `location:"none"` appear in the list only; geolocation granted using a **test fixture snapshot with explicit coordinates** (not the live data) → blue dot visible, nearest + distance + bearing equal precomputed values; mark #9 visited → nearest changes; denied → message; **no request URL or body contains the mocked lat/lng** (route interception on all requests); WebGL2 unavailable path (`--disable-webgl` / stub) → fallback view.
  - print: page loads with `?paper=letter-portrait` and `letter-landscape`; "Map ready" within 10 s; number of SVG markers == located snapshot houses; legend count == all published houses; mismatched `extentHash` shows the "being updated" message; adding a house to the fixture snapshot → appears; removing → disappears; no GPS marker/nav in `emulateMedia({media:'print'})` screenshot; attribution text present; `page.pdf({format:'Letter'})` produced and its 1st page screenshot archived for visual review.
  - pwa: rollback stub `sw.js` unregisters and clears caches; data-only change does not change the SW version; manifest fetch + JSON validity (name, start_url resolves to homepage, scope, icons exist with declared sizes); SW registers with scope = base; offline reload of `/`, `halloween/` succeeds (context.setOffline); updated snapshot version served after reconnect (bundled v1 → live v2 shown); old caches deleted after version bump; `christmas/` with `status: published` stub renders link card.
- **Lighthouse (run pre-merge via `npm run lighthouse`, not on every PR; mobile, local server)** budgets: Home — Perf ≥95, A11y 100, LCP ≤2.0 s, CLS ≤0.05, TBT ≤100 ms, initial transfer ≤350 KB.
